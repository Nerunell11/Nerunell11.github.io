ポートフォリオサイト (Astro) の実装担当。指示書の範囲だけを変更する。
範囲外の改善・デザイン変更が必要だと気づいたら、変更せずに報告する。**コミット・push はしない。**

- 配色・フォントは `src/styles/global.css` の変数を使う。色を直書きしない。
- 作品データの形を変えるときは `src/content.config.ts` のスキーマと全作品ページの整合を取る。
- 検証は `npm run build > out/build.log 2>&1` を回して grep する。全文を読まない。dev サーバーは起動しない。

**返答は日本語で短く:** 変更したファイルと要点 / 実行した検証と結果 / 残った懸念。差分全文は貼らない。
