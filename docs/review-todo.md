# 外部レビューの積み残し

2026-11-05 に ChatGPT と Gemini にサイトをレビューしてもらい、ソースと突き合わせた結果のうち、まだ手を付けていないもの。

## 対応済み (2026-11-05)

- Skills の 5段階バーを廃止 (`src/data/skills.ts`, `src/pages/index.astro`)
- Nexus の「並列実行の結果は直列実行と一致する」に前提条件と保証対象外を追記
- Nexus の設計論 (厚い抽象を採らない理由・Vulkan から実装する理由) を、一般論ではなく Nexus の要件に基づく判断として書き直し
- 「公開中」バッジを追加 (`released: true`)。AssetConverter に適用

## やること

### 文章化 (本人の聞き取りが材料)

- [ ] チーム作品 (Sentiment / TriGear / Ballistic / Hitoriga) に短い節を足す
  - 自分が決めたこと (技術選定・方針)
  - メンバーと協働で決めたこと (インターフェースの切り方など)
  - 自分の改善で変わったこと (数字があれば)
  - 未達成の部分・反省点
  - Ballistic はネットワーク担当なので、遅延・切断・同期ずれのテスト結果があれば載せる

### 計測・素材 (Nexus / AssetConverter 側の作業が要る)

- [ ] Nexus: ECS の直列実行との比較と、1 / 2 / 4 / 8 / 16 スレッドのスケーリング計測。平均だけでなく p95 / p99、計測条件、再現手順も
- [ ] Nexus: NexusDefense の動画 (いまは表だけ)
- [ ] Nexus: DX12 と Vulkan で同じシーンを描いた比較画像
- [ ] AssetConverter: 変換前後の画像と VRAM 量、変換速度、`.acpk` と ZIP の読み出し速度比較。ページ冒頭に置く

### ソース公開後

- [ ] 各作品の frontmatter `links` にリポジトリと、重要ファイル (例: Nexus のスケジューラ・テスト・ADR) への直リンクを追加

## やらないと決めたもの

- インターン (フロム・ソフトウェア) の詳細: NDA のため書かない。現状の「NDA のため詳細は非公開」のまま
- 開発中作品に完成度 (◯%) を書く: 根拠が作れないので書かない
- Skills を「使った作品と用途」の一覧に置き換える: バーの廃止だけにした

## レビュー側の誤読だった点 (対応不要)

- 「なぜ自作したか・アーキテクチャが見えない」(Gemini) → Nexus は問題→方法→構成図・クラス図・実行フローまで書いてある
- 「動画が無い」(Gemini) → Nexus (NightCrossing)・AssetConverter・TriGear に動画あり
- 「p99・計測環境が無い」(ChatGPT) → 環境・p99・1回計測であることは書いてある。足りないのは直列比較とスケーリングだけ
- 「3D・音声を削った判断をもっと強調」(ChatGPT) → AssetConverter に「対象を2D素材だけに絞った」節が既にある
