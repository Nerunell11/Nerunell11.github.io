アセットを読み込み、実行時に使える形へ変えるモジュールです。画像・モデル・フォントのパーサを自作していて、FBX SDK や assimp のような外部ライブラリは使いません（ADR 004、ADR 010）。

### アセットデータベース

クックした `.nxpak` をマウントして、アセット ID から中身を引く層です。パックのバイト列を所有し、圧縮していないエントリはコピーせずにそのまま見せます（ADR 017）。

元のファイルのパスからも引けます。マテリアルがテクスチャをソースのパスで持つので、クックのマニフェストから「パス → ID」の索引を作ります。マウントは複数回でき、同じ ID は後からマウントしたほうが勝つので、差分のパックでベースを置き換えられます。

### クッカー

画像（PNG / JPEG）はミップマップ付きにして、BC1 / BC3 / BC5 の圧縮を選べるテクスチャにします（ADR 016）。メッシュ（glTF / glb / FBX）、マテリアル、フォントもクックします。知らない形式のファイルは、黙って捨てずにそのまま格納します。

実行ファイルは `NexusCook` です。入力フォルダを `.nxpak` にまとめ、指定すればマニフェストも書き出します。マニフェストの並びを ID の昇順に固定しているのは、書き出す順序が実行ごとに変わらないようにするためです（ADR 017）。

### 画像パーサ

PNG、JPEG、EXR を読みます。JPEG はベースラインのみで、プログレッシブ形式には対応していません（ADR 010）。EXR は、PIZ と DWAA / DWAB の圧縮を展開できます。クッカーの対象は PNG と JPEG で、EXR は入っていません。

### モデルパーサ

glTF（glb と、埋め込み形式の gltf）とバイナリ FBX を読みます。FBX は、スケルトン・スキン・アニメーションも対象です（ADR 022）。ASCII 形式の FBX は対象外です（ADR 010）。FBX の外部テクスチャは、パスだけを返します。

### フォント

TrueType のフォントを読み込んで、グリフごとに寸法と文字の形をラスタライズします。クッカーを通すと `.ttf` / `.otf` のフォントとして格納されます。エディタの新しい UI では、使われた文字だけを動的にアトラスへ載せます（ADR 037）。
