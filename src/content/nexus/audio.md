音を鳴らすところから OS への出力までのモジュールです。音声の再生は OS の API を直接使い、ミキサも自作しています（ADR 004）。

### ミキサと DSP

ミキサのボイスは最大 64 で、ボイスごとに音量とパンを持ちます。メインスレッドからの再生・停止・音量変更は、固定長のコマンドキューに積んでオーディオスレッドが取り出します。WAV は PCM 16/24bit と IMA ADPCM を読めます。

フィルタ（ローパス・ハイパス）とフィードバックディレイは、ミキサとは別のクラスとして用意してあります。ミキサの中でこれらを呼ぶ処理は、まだ入っていません。バスの階層もありません。

### 3D 音響

聞き手と音源の位置から、距離による減衰（線形・逆数・指数）を計算して、音量とパンに変換します。残響ゾーンの選択とブレンド、遮蔽による減衰も、副作用のない関数として書いてあります。

これらの結果をミキサへ渡す処理は実装途中です。残響の効果自体も、ミキサにはまだつながっていません。

### ストリーミング

長い音は、デコード済みの PCM を少しずつ渡す `IAudioStreamSource` から再生します。先読み用のスレッドがリングバッファへ書き込み、ミキサはその連続領域を直接混ぜるので、サンプルごとの仮想呼び出しは起きません。

実装があるのは WAV だけです。Vorbis や Opus のような圧縮コーデックは、追加する前に ADR 004 の方針を見直すと決めてあります。

### WASAPI 出力

Windows の WASAPI を直接呼びます。共有モードで、イベント通知で動く専用スレッドがミキサの出力を OS へ渡します。デバイスの形式が PCM でも浮動小数でも受けられます。miniaudio のようなライブラリは使っていません。
