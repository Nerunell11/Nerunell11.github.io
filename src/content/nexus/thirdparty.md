Nexus は外部ライブラリに頼らず自作するのが原則です。例外は「OS とツールチェーン相当のもの」に限り、増やすときは ADR 004 を改訂する決まりにしています（これまでに 5 回）。例外にしたものは次のとおりです。

- **OS の API（Win32 など）**: 必須。対象が Windows のみなので、ウィンドウ、入力、ファイル、クラッシュダンプは OS の API を直接呼びます。
- **Direct3D 12**: Windows の描画 API として使います。DirectX 12 Agility SDK も例外に含みます。バックエンドは実行時に選ぶ形で、既定は Vulkan です。
- **Vulkan**: ビルドに必須です（CMake が Vulkan SDK を要求します）。GPU のドライバとあわせて、描画 API は自作しない領域としています。
- **DXC**: シェーダコンパイラで、HLSL を DXIL と SPIR-V に変換します。自作が非現実的なので例外にしました（ADR 002、ADR 004）。
- **WASAPI**: OS の API です。音の出力はこれを直接呼び、ミキサは自作です。
- **Dear ImGui**: インゲーム UI とデバッグオーバーレイ用で、ソースをリポジトリに同梱しています。描画のバックエンドは自作です（ADR 012）。
- **.NET（CoreCLR）**: 任意。言語ランタイムはツールチェーン相当とみなしました。ホスト層は自作で、.NET のホスティング SDK が見つからなければ、使えない状態としてビルドされます。エディタの新しい UI は .NET SDK（10.x）を前提にします（ADR 037）。
- **Python（CPython）**: 任意。組み込み用の開発ランタイムが見つかったときだけ有効になります。
- **DLSS / FSR**: 任意。ベンダー製のノイズ除去とアップスケーリングの呼び出しに限った例外です。ライセンスの都合でリポジトリには含めず、取得用のスクリプトで落とします。無くても自作の SVGF でビルドが通ります（ADR 032）。

例外リストには libsodium（ネットワークの暗号化）もありますが、まだ組み込んでいません。Windows App SDK / WinUI 3 は旧エディタのシェル専用の例外で、C# の UI への移行で不要になる予定です。
