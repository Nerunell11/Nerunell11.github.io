# 並列 ECS を中核に、DX12 と Vulkan を自作 RHI で抽象化

- 高いパフォーマンスと高品質なグラフィックスの両立が狙い
- Windows をターゲットにしている
- OS とツールチェーン以外は原則自作する
- 数学・コンテナ・アロケータから、PNG / JPEG / EXR / FBX / glTF のパーサ、ネットワーク層まで

---

# 例外と RTTI を使わない設計の制約

<v-clicks>

- **例外と RTTI を使わない**
- エラーは `Result<T>` とアサートで扱う
- `new` / `delete` は直接書かず、アロケータ経由で確保する
- ゲームロジックは **C# でも書けるようにする**計画
- CoreCLR を読み込むホスト層を自作済みで、C# の関数を呼べる段階

</v-clicks>

# 計測自体が壊れていたことに気づいて直した

<v-clicks>

- ベンチの弾は飛距離 60 に対し、敵は 118 ユニット先に湧いていた
- **弾は一度も敵に届かず、撃破 → 破棄 → 補充を測っていなかった**
- レーン型に変えて発射点を壁へ移したときに壊れていた
- 煙と火花を足したとき、枚数の列が全段 0 で気づいた
- 弾速を直した後、80万体の段で Spawn/Destroy は 1.28 ms

</v-clicks>

# 見た目を数値で検証する

NightCrossing — 荒天の夜に灯台へ向かう統合レンダリングデモ

- 240 フレーム走らせ、読み戻した画像から 22 項目を自動判定
- **すべての判定に下限と上限の両方**を置く
- 起伏と縞は逆方向に効くので、両方を満たす必要がある
- 黒い矩形が出たり出なかったりする不具合を踏んだのが発端

::right::
